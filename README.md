# Chest & Lava Finder (Fabric 1.21.11)

Клиентский мод:
- **G** — вкл/выкл подсветку сундуков сквозь блоки (оранжевый — сундук, красный — ловушка, фиолетовый — эндер-сундук, голубой — бочка).
- **H** — вкл/выкл подсветку лавовых озёр (только в верхнем мире, только скопления больше 10 блоков-источников).

Блоки мира не меняются — поверх рисуется только контур (как у эффекта «Свечение»).
Клавиши можно переназначить: Настройки → Управление → «Chest & Lava Finder».

## Как собрать .jar через GitHub (без установки Java)
1. Создай новый репозиторий на github.com.
2. «Add file → Upload files» → перетащи ВСЁ содержимое этой папки (включая скрытую папку `.github`) → Commit.
   Если папка `.github` не загрузилась — создай файл вручную: «Add file → Create new file», имя `.github/workflows/build.yml`, вставь содержимое.
3. Вкладка **Actions** → сборка «Build mod» запустится сама (2–4 минуты).
4. Открой завершённую сборку → внизу **Artifacts → chestlavafinder-jar** → скачай zip, внутри `chestlavafinder-1.0.0.jar`
   (файл `-sources.jar` не нужен).
5. Положи jar в папку `mods` (нужен Fabric API для 1.21.11).
